# ResumeLab_AzureCloud
Resumo do aprendizado sobre os fundamentos do Microsoft Azure aprendidos no curso da DIO.

Além de entender bem o que é o Microsoft Azure, aprendemos também como ele funciona, como fuinciona o Armazenamento em nuvem (Cloud) e como ela é importantemente utilizada em cada cenário. Vimos um pouco da história da Microsoft e como surgiu a computação em nuvem, quais são seu fundamentos, desafios e benefícios, além de tambem ver como criar uma conta gratuita de estudante.
